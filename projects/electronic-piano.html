ACADEMIC & ENGINEERING PROJECT

Electronic Piano Using 555 Timer IC

Associated with MKSSS Cummins College of Engineering for Women

Project description

Designed an electronic piano circuit around a 555 timer operating in astable-multivibrator mode. The circuit uses a resistor network, potentiometer, capacitors, speaker, and six push buttons to create tones with different pitches.

Pressing each button changes the effective resistance and therefore the oscillator frequency, producing a distinct audible note. The project documentation includes the circuit principle, components, and operating explanation.
