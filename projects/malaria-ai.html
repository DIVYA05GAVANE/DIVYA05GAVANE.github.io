Comparative Analysis of Malaria Detection Techniques using AI

Python, NumPy, deep learning

Overview

Compared CNN, ResNet-50, VGG-19 and an ensemble CNN approach for malaria-cell image classification. The work covered literature review, dataset preparation, parameter exploration and comparison using accuracy, precision, recall and F1 score; the ensemble model reached 95.22% accuracy.
