ACADEMIC & ENGINEERING PROJECT

Adaptive Echo Addition and Removal of audio signals in MATLAB

Sep 2020 – Sep 2020

Associated with MKSSS Cummins College of Engineering for Women

Project description

Matlab platform used for echo addition and removal process for audio signals.

1. Echo added to an input signal by adding signal’s delayed and attenuated version to it using a comb filter.

2. Deterministic echo addition parameters include delay constant, sampling frequency, attenuation constant.

3. Echo removal done by adjusting delay and attenuation constant so, inverse of transfer function after multiplication by itself gives result 1, this is done by using Least Mean Square (LMS) algorithm.

  • DSP(PBL-Phase 1).pptx

    Comparison done between Least Mean Square (LMS) & Proportionate Normalized Least Mean Square (PNLMS) algorithms. The NLMS algorithm achieves good convergence in dispersive AIRs and for non sparse system. Its response time is less but in case of system containing sparse it shows low convergence. The increase in complexity is compromised by the algorithm’s performance. The computational Complexity of PNLMS is more than NLMS, so we select LMS for our project.

    Echo addition and removal from audio signals’ is all related to processing audio signals using MATLAB , where we are specifically generating echo in the clean signal using transfer function parameters. LMS algorithm utilizes a variable convergence factor minimizing the instantaneous error and used for Echo Cancellation.
